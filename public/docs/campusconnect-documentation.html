CampusConnect Project Portal — Architecture & Documentation

Department: Information Technology (IT) · Academic Year 2025-26

1. System Overview

CampusConnect is a centralized institutional portal enabling students, faculty, and external reviewers to discover final-year capstone projects across six academic departments.

2. Cloud Architecture

  • Authentication: Firebase Authentication supporting institutional Email/Password sign-in, password reset, email verification, and Google Sign-In.
  • Database: Cloud Firestore storing departments, moderated projects, approved team contacts, student achievements, per-user bookmarks, and last-10 recently viewed items.
  • Security: Attribute-based Firestore Security Rules enforcing admin verification via /admins/{uid}, strict field validation, and PII isolation.

3. Key Modules

  • Student Showcase (index.html): Department browser, multi-filter search, project detail modals, related project matching, and approved contact channels.
  • Authentication Portal (auth.html): Split-screen login, student registration with password strength validation, and role-verified admin sign-in.
  • Administrator Console (admin.html): Project CRUD, approval queue, Firebase Storage image & PDF documentation uploads, and user management.
